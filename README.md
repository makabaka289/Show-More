# Show-More

《杀戮尖塔2》（Slay the Spire 2）多人联机辅助 Mod —— **队友手牌与 Debuff 提醒（CardReminder）**。

纯客户端界面增强，不影响游戏本体机制，队友无需安装。

## 主要功能

1. **队友手牌实时显示**：战斗中在队友状态栏右侧单行按手牌顺序显示队友完整手牌（包含卡图、费用、升级与实时数值），抽牌/弃牌平滑过渡，超过 5 张也不换行。
2. **Debuff 卡牌高亮与可打出状态区分**：
   - 可对敌人施加易伤的卡牌：淡红色外框高亮 + 右上角易伤图标
   - 可对敌人施加虚弱的卡牌：淡绿色外框高亮 + 右上角虚弱图标
   - 中毒/灾厄等其他减益：对应颜色外框高亮 + 右上角图标
   - 普通可打出卡牌采用原版边缘高亮；队友不可打出的 Debuff 牌自动压暗并保留对应颜色外框。
3. **悬浮原位 3 倍放大**：鼠标悬停任意队友手牌可在原位平滑放大 3 倍并显示关键词提示，查看细节更轻松。
4. **出牌 Debuff 提醒**：当你打出卡牌而队友手里还有敌人未挂上的易伤/虚弱等减益牌时，弹出提醒（含游戏内 Debuff 图标），点击任意位置关闭；默认暂停首次出牌防误出（可在设置中关闭）。
5. **队友金币与药水状态**：在队友 ID 右侧显示金币数量（变动时平滑数字滚动 + 飘字）与独立药水区（获得新药水时 1 秒平滑滑入，隐藏原版药水动画，悬停可查看药水详情）。

## 依赖

- 游戏版本：`>= 0.113.1`
- [STS2-RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `>= 0.6.15`

支持在主菜单或局内暂停的 RitsuLib 模组设置中自由调整各项开关与缩放比例。

## 构建

需要 .NET 9 SDK，以及本机《杀戮尖塔2》与 `STS2-RitsuLib` 目录：

```powershell
.\build.ps1 -Configuration Release -Sts2GameDir "<游戏目录>" -RitsuLibRoot "<RitsuLib目录>" -Package
```

添加 `-Install` 可直接部署至游戏 `mods/CardReminder` 目录。
